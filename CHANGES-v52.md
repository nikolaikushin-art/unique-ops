# v52 — что изменилось

## Данные и безопасность
- Резервная копия (Настройки → Локальное хранилище): скачать данные / данные + файлы, восстановить из файла. Баннер-напоминание, если копии нет 7+ дней. Сброс данных предупреждает.
- Убраны элементы, не работающие без сервера: баннер 2FA, надпись «Все системы в норме». Почта по умолчанию скрыта (Настройки → Модули).

## Связи между модулями
- Жёсткие связи booking.order_id, booking.invoice_id, invoice.booking_id (раньше счёт и бронь склеивались по названию услуги). Старые данные сопоставляются запасным способом.
- «Создать заказ и счёт» — один клик (Финансы и карточка заказа). Предоплата попадает в журнал оплат.
- В заказе несколько услуг: основная + допы, скидка, предоплата, дата выдачи, вещи в авто. Допы, одобренные при осмотре, добавляются в заказ сами.
- Журнал оплат в счёте: частичные оплаты, способ, «Отменить платёж». Статус счёта и оплата брони считаются из журнала; «просрочен» вычисляется по сроку. «Оплатить» заменено на «Принять оплату».
- При завершении работ материалы по рецептуре списываются со склада (один раз), считается реальная себестоимость. Труд заказа = комиссия сотрудника, если задана.
- Касса: «Получено сегодня» по способам оплаты.

## Новые поля
Клиент: источник, канал связи, день рождения, теги, кто привёл. Авто: пробег, код краски, история покрытий. Услуга: гарантия и интервал обслуживания (мес.). Сотрудник: комиссия %. Заказ: скидка, предоплата, выдача, вещи в авто.

## Новые функции
- Печать / PDF: счёт, акт выполненных работ, гарантийный талон, приёмо-передаточный акт, смета. Реквизиты — Настройки → Система → «Реквизиты студии».
- Сообщения клиентам по шаблонам → WhatsApp / Telegram / Email, с записью в историю клиента.
- «Сегодня связаться» на Обзоре: готовые авто, просроченные счета, обслуживание и гарантия, «давно не были», дни рождения.
- Выплата сотруднику по комиссии — вкладка «Производительность».

## Исправления
- Календарь: в недельном виде — диапазон недели и шаг ±7 дней, все 7 дней помещаются; в видах «Техники» / «Боксы» убраны наползающие скруглённые ячейки, карточки не обрезаются.

## Исправления после v5
- Верхняя панель: возвращена иконка «Почта» (я по ошибке скрыл модуль), убрана «дыра» в середине панели, вместо фальшивого «Все системы в норме» — честный статус резервной копии; баннер копии сделан компактным.
- Email: кнопки «Email» у счёта, «Отправить счёт клиенту», письма из карточки клиента и отправка документов открывают вашу почтовую программу с готовым письмом и пишут его в историю клиента / Почту. (Без сервера отправить письмо прямо из браузера нельзя.)
- Строка статусов на странице броней: «Отменено» больше не обрезается — все статусы помещаются в одну строку, на узких экранах переносятся.
- Верхняя панель в стиле Apple: слева поиск, справа единый ряд (Почта · Оповещения · Настройки · статус копии | Быстрое действие · Профиль) с равными отступами 8 px, круглые иконки 34 px, аккуратные счётчики, тонкий разделитель, стеклянный фон; края совпадают с контентом, линия под логотипом в сайдбаре совпадает с нижней границей панели. Оповещения — иконка-колокольчик вместо текстовой кнопки.
- Верхняя панель целиком (включая поиск) сдвинута вправо в стиле iOS: компактное поле поиска в системном сером, расширяется при фокусе; результаты поиска раскрываются под полем по правому краю.
